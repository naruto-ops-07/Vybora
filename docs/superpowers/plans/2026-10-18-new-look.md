# New look (Velvet, Aurora, Bloom) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** VYBORA gets a premium, themed look: **Velvet by default**, with **Aurora** and **Bloom** as alternatives, each in light and dark. People choose in Settings → Appearance. The look applies to every surface of the website and the phone app.

**Architecture:**

- **One source of tokens:** `packages/config` holds all looks, as `looks[look]`: fonts, radii, elevation and per-mode colours, including gradient stops and glows. Personal tones become per look.
- **Web:** a generated CSS file sets every look as CSS variables, switched by `data-look` / `data-theme` / `data-contrast` on `<html>`, and is applied before first paint.
- **Mobile:** `useTheme()` resolves the same tokens.
- **Shared components first, then screens:** primitives (buttons, fields, cards, menus) are restyled from tokens first, then every screen.
- **High contrast:** keeps one flat token set per mode, shared by all looks. No gradients and no shadows.

**Tech Stack:**

- **Web:** Tailwind 4 (`@theme inline`), `@fontsource-variable/*` (self-hosted fonts).
- **Mobile:** `@expo-google-fonts/*` and `react-native-svg` gradients, with no gradient library.
- **Motion and tests:** Reanimated (mobile ambient motion), Vitest / Jest.

**Spec:** `docs/superpowers/specs/2026-10-18-premium-themes-features-design.md`, section 3, plus the "Empty chat list" and "Friends screen: requests" subsections. The owner chose Velvet in the brainstorm mockups: `.superpowers/brainstorm/929-1792304247/content/look-directions.html` (Velvet = option B).

## Global Constraints

- **Looks:** `velvet` (default), `aurora`, `bloom`.
- **Modes:** `light` and `dark`, plus the preference `system` (default).
- **Default appearance:** Velvet, system mode.
- **Storage:**
  - Per device, under key `vybora.appearance` (web `localStorage`, mobile SecureStore), as JSON `{ "look": …, "mode": … }`.
  - The old web key `vybora-theme` (`light` / `dark` / missing) is read once as the mode and then removed.
- **Anchor colours (from the spec and mockups; the builder derives the full sets and contrast tests decide):**
  - **Velvet dark:**
    - Base: bg `#0F0D0B`, raised `#1C1916`.
    - Outgoing bubble: gradient `#145244 → #0D3B31` with `#F3EDE4` text.
    - Accents: champagne `#D4B483`, primary button gradient `#E5CB9C → #C4A16C` with `#1A140C` text.
    - Text: `#F3EDE4`.
  - **Velvet light:** ivory `#FBF8F2`, warm-white raised surfaces, emerald `#0F5C4C` bubble with ivory text, gold `#9A7A45` accents.
  - **Aurora dark:**
    - Base: night `#060A13`; glows teal `rgba(20,184,166,.55)`, violet `rgba(124,58,237,.50)` and sky `rgba(56,189,248,.30)`.
    - Frosted panels: `rgba(255,255,255,.06)` with a blur.
    - Outgoing bubble: gradient `#14B8A6 → #6366F1`.
    - Text: `#EAF2FF`.
  - **Aurora light:** pale sky `#F4F7FB` with faint aurora tints, and the same gradient bubble.
  - **Bloom light:** pearl `#F7F5FC`, bubble gradient `#FF5E8A → #FF8E5E`, violet accent `#6D4AFF`, text `#1D1530`.
  - **Bloom dark:** plum night `#17121F`, with pink and violet glows.
- **Type:**
  - Velvet: Fraunces (display: titles, names, big numbers) + DM Sans (text).
  - Aurora: Sora + Manrope.
  - Bloom: Plus Jakarta Sans.
  - IBM Plex Mono stays for data only: timestamps, counts, codes.
  - Archivo is retired.
- **Radii per look:** Velvet 6/12/18, Aurora 8/14/20, Bloom 10/16/24 (sm/md/lg).
- **Still binding:**
  - WCAG 2.2 AA: text ≥ 4.5:1 and large text ≥ 3:1 in every look × mode. High contrast is ≥ 7:1, flat, with no gradients or shadows.
  - Touch targets ≥ 44 px; per-device text size works everywhere.
  - Reduced motion turns off all ambient motion and the delight animations.
  - Phosphor icons, no emoji as icons, sentence case.
  - No invented claims or testimonials; no message text outside chats.
- **Motion:** one ambient effect per look at most: Aurora's slow light drift, Bloom's soft glow pulse. Velvet has none. No hover lift or scale on controls.
- **Personal tones:** per look (`personTonesByLook[look]`). Velvet uses jewel tones, Bloom vivid ones, and Aurora keeps today's values exactly. Contrast tests run for every look.
- **Chat themes:** "Default" means the look's own outgoing bubble. The named chat-theme colours keep their colour, rendered with the look's depth.
- **New dependencies (exact versions, published ≥ 2 weeks ago, installed so the lockfile records them; nothing else):**
  - Web: `@fontsource-variable/fraunces`, `@fontsource-variable/dm-sans`, `@fontsource-variable/sora`, `@fontsource-variable/manrope`, `@fontsource-variable/plus-jakarta-sans`, `@fontsource/ibm-plex-mono`. Google Fonts `<link>`s are removed.
  - Mobile: `@expo-google-fonts/fraunces`, `@expo-google-fonts/dm-sans`, `@expo-google-fonts/sora`, `@expo-google-fonts/manrope`, `@expo-google-fonts/plus-jakarta-sans`, each in the same `0.4.x` line as the existing `@expo-google-fonts/archivo`.
- **No hosted Supabase calls, dev server against hosted, or browser sign-in:** visual checks use the dev gallery with sample data only.
- **All UI tasks run on Claude Opus 5.5 at top visual craft** (owner).
- **Tests:** real output only.

## Review Focus

1. **First paint:** the saved look and mode show on first paint with no flash of the wrong look. Web: a pre-paint script. Mobile: the splash stays until fonts and appearance have loaded.
2. **Switching at runtime:** switching look or mode recolours every visible surface immediately. That includes chat bubbles with a non-default chat theme, personal-tone names and avatars, illustrations and the Get started panel.
3. **High contrast:** in each look it is flat (no gradient or shadow anywhere) and meets 7:1, and reduced motion removes the ambient motion in every look.
4. **Large text on a 320 px-wide screen:** with the largest text size, nothing clips or overflows in any look. The serif display face is wider.
5. **Corrupt or old stored values:** garbage JSON, an unknown look, or old `vybora-theme` values fall back to Velvet with the system mode, without crashing, and the old key is migrated.
