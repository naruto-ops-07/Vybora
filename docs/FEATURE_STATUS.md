### Fixed this round

- **The verify job could not pass by construction.** `format:check` requires `packages/types/src/database.ts` to be Prettier-formatted, but `scripts/gen-db-types.mjs` emitted unformatted output, so the later drift gate always saw a diff. The generator now formats what it writes.
- **`pnpm typecheck` failed inside a dependency.** `src/components/Icon.tsx` deep-imports `phosphor-react-native` as TypeScript source across 70 icons, and its `icon-base.tsx` passes a NativeWind `className` that `react-native-svg` does not declare. Added `apps/mobile/types/react-native-svg.d.ts`.
- **Two stale e2e assertions.** The font check still demanded Archivo, dropped on 2026-10-18 in favour of DM Sans; and `getByRole('button', { name: 'New message' })` turned ambiguous once the chat-list empty state gained a button of its own.
- **CI never ran on feature branches.** It triggered only on `main` and pull requests, so work on `feat/**` went unchecked.
- **Generated files were tracked**: 1,364 under `.turbo`/`.tmp`, Playwright's `.last-run.json`, and 20 bytes of UTF-16 appended to `README.md`.

### Known, not fixed

- **`applock.test.tsx` leaves the Jest process hanging.** All 194 mobile tests pass, but the process stays alive long after the run (94 s of tests, still up at 3 m 50 s) and `--detectOpenHandles` reports nothing. Ruled out: the `AppState` listener in `AppLockCover` (it removes its subscription), `subscribeAppLock` (returns an unsubscribe), `packages/core/src/appLock.ts` (no timers), Supabase auth (mocked in the suite) and fake timers (not used). It does not fail CI.
- **82 MB of turbo cache remains in git history** — 1,046 objects, `.git` is 209 MB. Untracking stopped new ones accumulating; clearing the old ones needs a history rewrite.

## Known limitations

- **Encryption** is not independently audited (nor is the `ts-mls` library). See [CONNECT.md → Limitations](CONNECT.md#limitations).
- **No calls, group photos, custom uploaded tones, or contact sync.** Message editing is web-only; the phone shows edited messages but cannot edit.
- **New devices** see only messages sent after they were added.
- **Web** does not record voice notes (it plays them). Web key storage is weaker than the phone keychain.
- **Mobile history** shows the newest 500 locally stored messages per chat (no "load earlier" yet).
- **Reports** are stored in the database but there is no in-app review console; the operator reviews them with SQL.
- **App Store export compliance**: `ITSAppUsesNonExemptEncryption` is `false` in `app.json`. Now that the app implements end-to-end encryption this must be reviewed before submission.
- **Usernames are searchable** by any signed-in user (needed to start chats); there is no discoverability opt-out yet. Friend requests use exact usernames only.
- **Mobile share links** include the `?add=` web link only when `EXPO_PUBLIC_SITE_URL` is set; otherwise the share sheet carries just the `@handle`.
- **Email codes don't fully hide which emails have accounts.** The sign-in-by-code screen is neutral, but sign-up says "That email already has an account", and the Supabase API answers an unknown address differently. See [SECURITY.md](SECURITY.md#email-codes-and-account-enumeration).
- **Email OTP expiry is one setting:** at 10 minutes, the confirmation, magic and password-reset links also expire after 10 minutes.
